# Git Basics

1. Initialize repository command

   `git init`

2. Status command

   `git status`

3. Add or stage files command

   `git add <filename1> <filename2>`

4. Add or stage all files at once command

   `git add .`

5. Commit the staged files command

   `git commit -m "<commitMessage>"`

6. Logs commit history command

   `git log`
